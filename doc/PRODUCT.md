# Product

## Register

product

## Users

Vibe coders, solo founders, and hackathon builders who can ship with Cursor but struggle to define MVP scope, features, and implementation specs before coding.

## Product Purpose

SpekDulu turns a vague product idea into a locked MVP blueprint and Cursor-ready artifacts. It interviews the builder, cuts unnecessary features, generates design and implementation context, and optionally analyzes screenshots or public URLs as visual references. Success means a builder can go from messy idea to a reusable Cursor Skill with clear acceptance criteria in minutes.

## Brand Personality

Calm, decisive, builder-friendly. SpekDulu feels like a senior product architect sitting next to a vibe coder: clear, focused, and anti-scope-creep.

## Anti-references

- Generic Bootstrap or Material admin dashboards
- Neon cyberpunk AI aesthetics
- Heavy purple gradients and visual clutter
- Document dump tools that generate long PRDs without deciding scope
- Exact website cloning tools that encourage trademark risk

## Design Principles

1. Decide before documenting. Scope cuts matter more than document count.
2. Progressive disclosure. One primary action per step.
3. Cursor-native output. Generated Skills and tasks must be executable.
4. Honest confidence. Label estimates, inferences, and assumptions clearly.
5. Demo resilience. The product works in demo mode without API keys.

## Accessibility & Inclusion

Target WCAG AA contrast, keyboard-accessible flows, visible focus states, semantic structure, and reduced-motion support. Copy should stay plain and readable for non-native English builders.
